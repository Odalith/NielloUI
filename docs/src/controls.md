# Controls

> This chapter is being written.

niello/controls: buttons, switches, check boxes, radio groups, combo boxes, tooltips, the text box, sliders, progress bars, scrollbars and captioned fields, and the theme, type and spacing roles they share.

A control's `label` names it for screen readers. Check boxes and radio options draw theirs (and wrap a long one); for a combo box, a slider or a text box, put the control in a [`field`](reference/controls.md#field) block to show a caption above it.
