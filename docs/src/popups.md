# Popups and dialogs

> This chapter is being written.

Overlay roots: dropdowns, context menus, tooltips and modal dialogs, with dismissal reported to you.

[`dismiss_requested`](reference/niello.md#dismiss_requested) says the user asked to close a popup; [`dismiss_reason`](reference/niello.md#dismiss_reason) says whether it was Esc or a press outside, so a dialog can close on one and not the other.
